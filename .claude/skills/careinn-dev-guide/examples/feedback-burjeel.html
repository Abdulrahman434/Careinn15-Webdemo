Feedback screen — Burjeel

Burjeel collects feedback through its own printed QR posters. The Feedback screen shows one card per poster, and a tap opens that poster so the patient can scan it with their phone. Today there are two posters. This guide also sets how the screen grows when Burjeel adds a third, fourth or more. Read it with the CareInn Bedside UI Build Guide and Revision 1.

FB.4

More than two cards

New★ The rule

When Burjeel sends a new poster, add one more card. Don't make the cards smaller or bigger, and don't change the gaps. Fill rows of up to three, keep the rows as even as you can, and keep the whole group centred.

The rule

  1. Card size never changes: 416 dp wide, 24 dp apart, in both directions.
  2. Three cards at most in a row. Rows = cards ÷ 3, rounded up.
  3. Rows as even as possible: cards per row = cards ÷ rows, rounded up. The top row gets the extra card.
  4. A shorter last row is centred under the row above.
  5. The group is centred in the panel, both ways.
  6. Six cards at most. Two rows fill the panel; a third row doesn't fit.
rows = ceil(n / 3) perRow = ceil(n / rows) groupW = perRow × 416 + (perRow − 1) × 24 groupH = rows × 336 + (rows − 1) × 24

What it looks like

The extra cards in these pictures are made-up examples. They all show the clipboard icon only because they were copied for the picture: each real card gets its own icon (FB.5).

Do
  • Keep every card 416 dp wide, at every count.
  • Work out the rows from the number of cards, with the rule above.
  • Give every card in a row the same height.
Don't
  • Don't stretch the cards to fill the panel width.
  • Don't shrink the cards, the icon or the text to fit more in a row.
  • Don't build a separate layout for 3, 4 or 5 cards. One rule covers every count.
The other hospitals' Feedback screens use the same card and the same rule: three cards in one row, 1296 dp wide. One card and one grid serve every hospital.

FB.5

Order and wording

New

Every card reads the same way: an icon, a short name, and one line that says where it goes, ending in "Scan QR".

Order

  1. Rate Us (Google Maps review) is always first.
  2. Patient Form is second.
  3. New posters follow in the order Burjeel sends them. Add each new one at the end, so the first cards never move.

FB.6

Poster view

New

A tap on a card shows its poster inside the white panel, as large as the panel allows. The top bar stays visible and usable. A tap on ✕ or anywhere outside the poster closes it.

Dimcovers the white panel only, follows its 32 dp corners · #59000000 (black 35%)#99000000 (black 60%)

Java
// panel: the white panel (FrameLayout, clipToOutline = true, 32dp corners)
void showPoster(FeedbackPoster p) {
    View dim = getLayoutInflater().inflate(R.layout.feedback_poster, panel, false);
    ImageView img = dim.findViewById(R.id.posterImage);
    View close = dim.findViewById(R.id.posterClose);
    img.setContentDescription(getString(p.titleRes));
    img.setImageResource(p.posterRes);                      // scaleType="fitCenter", adjustViewBounds="true"

    dim.setOnClickListener(v -> hidePoster(dim));          // tap outside closes
    img.setOnClickListener(v -> { /* tap on the poster: nothing */ });
    close.setOnClickListener(v -> hidePoster(dim));

    dim.setAlpha(0f);
    panel.addView(dim);
    dim.animate().alpha(1f).setDuration(150).start();
    getWindow().addFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON);
}
// onBackPressed: if a poster is open, hidePoster() first and stop.

FB.7

Poster files

New

Each poster is Burjeel's own print design. Show it as it is: no text on top, no crop, no recompression.

PartValue
Files todayburjeel_google_review_qr.jpg · burjeel_patient_form_qr.jpg · 901 × 1280 px each
Shapetall, about 1 : 1.42 (A4 / A3). Every poster the same shape, so they all open at the same size.
Sizeat least 900 px wide and 1280 px tall, so the QR stays sharp at 870 dp on screen.
FormatPNG, or JPEG at quality 90 or higher. Put it in res/drawable-nodpi/ so Android doesn't rescale it.
QR codemust scan from about 30 cm on the screen. Test each new poster with two phones before release.
Languagesthe posters are already English + Arabic. One file for every app language.
Dark modesame file. The poster keeps its own white background.

If a new poster comes in a different shape, send it back to us rather than fitting it. Mixed shapes make the poster view jump in size from card to card.

FB.8

Arabic and Urdu

New

The whole screen mirrors. The order of the cards follows the reading direction, so Rate Us is on the right.

  • Lay the grid out with start/end, so rows fill from right to left. A shorter last row stays centred.
  • The ✕ on the poster moves to the top-left corner (top|end does this for you).
  • The poster image does not mirror.
  • Arabic and Urdu text uses Almarai at the same sizes. Keep font padding and the 1.5 line height (Build guide → 11 Arabic text cropping).
  • The star and clipboard icons don't mirror.

FB.10

Build it from a list

New

Keep the posters in one list. The screen reads the list, works out the grid from its length, and adds one card per entry. A new poster is one new line in the list, with no layout change.

Java · the grid
static final int CARD_W = 416, GAP = 24, MAX_PER_ROW = 3;   // dp

/** Cards per row: rows of up to 3, rows balanced (4 → 2 + 2, 5 → 3 + 2). */
static int columns(int n) {
    int rows = (n + MAX_PER_ROW - 1) / MAX_PER_ROW;   // ceil(n / 3)
    return (n + rows - 1) / rows;                     // ceil(n / rows)
}

/** Width of the card group, in dp: 416 · 856 · 1296. */
static int groupWidth(int n) {
    int cols = columns(n);
    return cols * CARD_W + (cols - 1) * GAP;
}
XML · the group (FlexboxLayout)
<!-- inside the white panel, padding 0 64 -->
<FrameLayout
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <!-- width: set from groupWidth() · justifyContent center: centres a shorter last row
         alignItems stretch: same height in a row · space_24: a 24 × 24 transparent shape -->
    <com.google.android.flexbox.FlexboxLayout
        android:id="@+id/feedbackGroup"
        android:layout_width="856dp"
        android:layout_height="wrap_content"
        android:layout_gravity="center"
        app:flexWrap="wrap"
        app:justifyContent="center"
        app:alignItems="stretch"
        app:showDivider="middle"
        app:dividerDrawable="@drawable/space_24" />
</FrameLayout>
  1. Set the group's width from groupWidth(), then inflate one item_feedback_card per list entry.
  2. The group sits in the centre of the panel. Up to six cards always fit, so the panel never scrolls.
FlexboxLayout comes from com.google.android.flexbox:flexbox:3.0.0. A GridLayout with a fixed column count also works, but it can't centre a shorter last row, so 5 cards would sit to one side.
